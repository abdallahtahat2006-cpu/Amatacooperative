# الموقع الرسمي لـ تعاونية عمّتا متعددة الأغراض محدودة المسؤولية
### Amata Cooperative Official Website

الموقع التعريفي والتفاعلي الرسمي لـ **تعاونية عمّتا متعددة الأغراض محدودة المسؤولية**، المسجلة وفق أحكام قانون التعاون الأردني، وتتخذ من محافظة البلقاء مركزاً لها.

---

## 🚀 المميزات الرئيسية
- **دليل تفاعلي متكامل:** استعراض غايات التعاونية، الهيكل التنظيمي واللجان، شروط العضوية والانتساب، وبيانات الاكتتاب والأسهم.
- **واجهة مستخدم عصرية ومتجاوبة:** تصميم متكامل للشاشات المكتبية وشاشات الهاتف مع قائمة تنقل زجاجية متقدمة (Glassmorphism Bento Navigation).
- **قنوات تواصل مباشرة:** ربط مباشر بالاتصال الهاتفي، المراسلة الفورية عبر WhatsApp، والبريد الإلكتروني المعتمد.
- **تحميل الوثائق المعتمدة:** إمكانية تحميل النظام الأساسي والملف التعريفي بصيغة PDF.

---

## 🛠 التقنيات المستخدمة (Tech Stack)
- **Framework:** [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Routing:** [React Router DOM](https://reactrouter.com/)

---

## 💻 التشغيل والتطوير المحلي (Local Development)

### 1. تثبيت الحزم (Dependencies):
```bash
npm install
```

### 2. تشغيل سيرفر التطوير (Dev Server):
```bash
npm run dev
```

### 3. بناء المشروع للإنتاج (Production Build):
```bash
npm run build
npm run preview
```
